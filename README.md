# Prompts for One

Escenarios y acciones para sacar el máximo partido a Factorial con One, filtrables por rol y por módulo, en 8 idiomas.

- `index.html`: la página.
- `data.js`: escenarios y acciones (rol, módulo, dónde lanzarlo).
- `i18n/<idioma>.js`: textos de cada idioma.
- `names.js`: nombres de áreas y módulos (los mismos que el mapa One).

Idioma por enlace: `?lang=en`, `?lang=de`, `?lang=fr`, `?lang=it`, `?lang=pt`, `?lang=pt-br`, `?lang=pl` (sin parámetro: español).
